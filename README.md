# ?? Prashant's Portfolio

> Interactive 3D portfolio website built with Three.js and GSAP

## Features
- Three.js animated particle background
- 3D rotating geometric shapes
- Typing animation
- 3D skill orbs
- Project cards with 3D flip animation
- Custom cursor with trail
- Glassmorphism design
- Fully responsive

## Tech Stack
| Technology | Purpose |
|------------|---------|
| HTML5 | Semantic markup |
| CSS3 | Animations, glassmorphism, dark theme |
| JavaScript | Interactivity and 3D rendering |
| Three.js | 3D particle background and shapes |
| GSAP | Smooth scroll animations |
